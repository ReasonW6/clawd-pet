性格

活跃度两件事之间歇多久：悠闲约 1 分钟，活泼十几秒，闹腾几乎不停；安静就只待着
例外的程序这些程序全屏时它不躲，陪你看视频。主流浏览器和视频软件已经在里面
你的生日当天它会给你吹蜡烛

互动小贴士：单击逗它、连点 5 下会生气（开了 AI 聊天时没有）、双击随机表演（开了 AI 聊天就是和它聊天）、鼠标在它身上来回蹭是摸摸、按住可以拎着走、把文件拖到它身上它会接住。

作息

不超过 3 小时的时段算打盹（看书睡着），更长的算正式睡觉（盖被子）。睡着时 Claude 一开工它会惊醒干活，忙完再接着睡；戳它也会醒，但会有点起床气。

Claude 联动

Claude Code 联动 向 ~/.claude/settings.json 写入一组 HTTP hook（会先备份）。终端、Desktop、VS Code 里的 Claude Code 都会生效。

桌宠没运行时 hook 会立即失败，Claude Code 照常工作，不受影响。

系统联动

让它对你在电脑上的操作有反应。只感知「发生了什么」，不读取文件内容、剪贴板内容和按键，全部在本机处理。Claude 干活时这些反应会自动让路。

Git 操作的原理：打开后会在你的全局 git 配置里加 4 行 trace2.* 设置，让 git 把每条命令的名字和结果记到桌宠自己的文件夹里；桌宠读完就删，只看命令名，不碰仓库内容。关掉开关即从配置里移除。桌宠没运行时 git 最多攒 200 个小文件就自动停记。
