一、Claude Code 联动

Claude Code 每发生一件事就通过 hook 通知桌宠。每个会话各记一个状态；多个会话同时在跑时，显示最紧急的那个：等你确认 > 压缩上下文 > 干活 > 思考。

二、它自己的生活

Claude 没活给它的时候，它过自己的日子：演完一个场景，歇一会儿，再演下一个。一个场景由一到几个动画按顺序接成（图里的箭头就是顺序），循环的那几步平分 20–50 秒，标了 ×N 的只播 N 遍；只有一个动画的场景播 20–30 秒。歇多久由「活跃度」决定：悠闲 30–70 秒（约三分之一时间在活动），活泼 10–25 秒（约六成），闹腾 3–8 秒（约八成），安静则只待着不演场景。任何别的事（Claude 开工、你逗它、系统事件）都会打断当前场景，之后至少安静 6 秒再接着过日子。

下一个场景怎么抽

按下表的权重抽一个种类，再从这个种类里挑一个最近没演过的场景。两行权重分别对应你在用电脑和键鼠一阵没动静（你可能走开了，也可能在看视频）：后一种情况下它更爱运动和变装，同时会无聊、想你。小字是平常时段里的占比。

  • 看时间：每个作息时段会把某些种类调多或调少（写在下面每个时段里），比如傍晚运动 ×1.8、深夜不运动。
  • 有连续性：演完爱好、音乐、运动、角色扮演、家务、小项目里的一种，有 40% 的可能接着演同一种（最多连 3 个），所以会出现「连着练几项」「连换几套衣服」。

情绪

情绪不是一个动画，而是一段时间的状态：歇着的姿势换成这种情绪的，抽场景时多一份权重 30 的「情绪场景」。鼠标停在它身上，标签会写出当前心情。发生了事引起的情绪（开心、得意、被宠着、闹脾气、郁闷）优先于处境带来的（无聊、想你、犯困）。

五、系统联动

对你在 Claude Code 之外的操作做反应。全部是「一次性 · 让路」：Claude 正忙时不显示，它睡着时不理会。同一种事件默认 20 秒内只反应一次。每项都能在设置的「系统联动」里单独关掉。status、fetch、log 这类编辑器在后台反复执行的 git 命令，以及别的 git 命令派生出来的子命令，都不触发。
